ℹ️ Tentang Dashboard

Dashboard ini menampilkan data ISPU resmi dari KLHK secara real-time. Data diambil langsung dari portal ispu.kemenlh.go.id melalui Cloudflare Worker, tanpa perantara pihak ketiga.

Cara Kerja:
1. Dashboard memilih stasiun KLHK terdekat dari koordinat desa
2. Data diambil dari API internal KLHK via Cloudflare Worker
3. Nilai ISPU ditampilkan beserta rekomendasi keputusan

⚠️ Data ini adalah ISPU resmi (Permen LHK 14/2020), bukan estimasi model. Untuk keputusan kritis, verifikasi dengan kondisi lapangan.
