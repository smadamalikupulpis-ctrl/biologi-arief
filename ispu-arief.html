ℹ️ Tentang Dashboard

Dashboard ini dibuat untuk membantu pengambilan keputusan pembelajaran (Normal / Terbatas / Daring) berdasarkan kualitas udara real-time di wilayah Maliku, Basarang, dan Selat Kapuas, Kalimantan Tengah.

Sumber Data:
• Open-Meteo (Air Quality API) — model CAMS Eropa, resolusi ~45 km
• Sensor.Community — sensor partikel warga, open source
• KLHK ISPU — link manual ke portal resmi

⚠️ Data Open-Meteo bersifat estimasi model satelit, bukan pengukuran langsung. Untuk keputusan kritis, selalu verifikasi dengan data resmi KLHK dan kondisi lapangan.
