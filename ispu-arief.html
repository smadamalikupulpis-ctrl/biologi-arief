ℹ️ Tentang Dashboard

Dashboard ini membantu pengambilan keputusan pembelajaran (Normal / Terbatas / Daring) berdasarkan kualitas udara real-time di Kalimantan Tengah.

Sumber Data:
• WAQI (KLHK) — sensor fisik resmi, acuan keputusan
• Open-Meteo — model satelit CAMS, info lokal
• Sensor.Community — sensor warga, open source
• KLHK ISPU — link manual ke portal resmi

⚠️ WAQI menggunakan standar AQI US EPA. Untuk keputusan kritis, verifikasi dengan kondisi lapangan.
